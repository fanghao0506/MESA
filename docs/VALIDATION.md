# Release validation

Validated locally on 2026-10-05 with Python 3.12.7, NumPy 2.3.1, SciPy 1.16.0,
PyTorch 2.5.1+cu121, Windows, and an RTX 4090 Laptop GPU. CUDA is optional.
Detailed numeric results are recorded in `validation.json`.

- All **13 tests passed**. Exact linear LOOCV selection was independently checked
  against explicit held-out-channel solves at all 61 candidate ratios.
- All three bundled EIT outputs matched the frozen manuscript prediction vectors
  **element-for-element**, on both CPU and CUDA in this environment.
- The extracted real-EIT solver matched the original four tactile and two signed
  biomedical outputs element-for-element. Those private observations were used
  only for local validation and are not included in this release.
- Two controlled ECT and two generated MPI inputs matched the original NumPy
  adapter element-for-element. Their external operators/data are not bundled.
- The Torch CPU, Torch CUDA, and NumPy demonstration commands completed.
- The project builds as a Python wheel without the original research directory.
- A fresh extraction of the release zip passed all 13 tests and the CPU demo
  with the original research paths absent from `PYTHONPATH`. A separate NumPy-only
  Python environment passed its eight tests and correctly skipped five optional
  PyTorch tests. The wheel was independently imported outside the source folder.

Regression tolerances remain `rtol=2e-5, atol=2e-6` to allow ordinary platform and
linear-algebra differences. Matching outputs here does not guarantee bitwise
identity on every dependency/hardware version. No new benchmark, parameter
search, runtime measurement, or manuscript change was performed.

This is a compact runnable release, not the full scientific archive. Aggregate
accuracy tables, factorial bootstrap intervals, and complete paper figures are
not regenerated by the three-case demonstration.
